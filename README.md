Uma suite completa de ferramentas de segurança para testes em sites e aplicações web. Desenvolvida para fins educacionais e testes de penetração autorizados.

##  Sobre o Projeto

O Security Tools Suite é uma ferramenta all-in-one que reúne 10 das mais importantes funcionalidades para testes de segurança web. Inspirada em ferramentas profissionais como Nmap, WPScan, Burp Suite e OWASP ZAP, esta suite foi desenvolvida para ser **completa, educacional e fácil de usar**.

###  Funcionalidades Principais

| # | Ferramenta | Descrição |
|---|------------|-----------|
| 1 |  **Port Scanner** | Scan de portas TCP com multi-threading e deteção de serviços |
| 2 |  **Directory Bruteforcer** | Descoberta de diretórios e ficheiros ocultos |
| 3 |  **Subdomain Enumerator** | Encontra subdomínios através de força bruta DNS |
| 4 |  **XSS Scanner** | Deteta vulnerabilidades de Cross-Site Scripting |
| 5 |  **SQL Injection Tester** | Testa injeções SQL em parâmetros |
| 6 |  **Security Headers Analyzer** | Analisa cabeçalhos de segurança HTTP |
| 7 |  **WAF Detector** | Identifica Web Application Firewalls |
| 8 |  **SSL/TLS Checker** | Verifica certificados e configurações SSL |
| 9 |  **Web Crawler** | Explora e mapeia a estrutura do site |
| 10 |  **Relatório Completo** | Executa todas as ferramentas e gera relatório |
